## #205 — die Live-Vorschau im Textfeld (2026-11-25, implementiert, Gerätematrix offen)

- **Kanal:** Das Diktat wächst während der Transkription über die Composing-Region im Zielfeld (`setComposingText`), ein Anzeige-Tick pro fertigem Fragment — **keine zusätzliche STT/LLM-Anfrage** (D2). Nach einer Rotation empfängt die neue Instanz `Completed(redelivered=true)` via `attach`; ohne den geteilten Zustand würde sie blind in ein Feld einfügen, das den Rohtext schon hält — das verbotene Duplikat (I5). Die `insertResultText`-Override-Naht bleibt für die vier bestehenden Robolectric-Klassen; die neuen Tests fahren ein `FakeEditor`-Modell, das `setComposingText` als **Ersetzen** der Region implementiert (genau die Semantik, über die die Policy nachdenkt).

## #133 — what shipped (`07d3006`, 2026-10-13)

- **Behaviour:** a successful send no longer leaves the voice keyboard as the default IME — the IME resolves the last-used typing keyboard (the same target the keyboard-switch button resolves) and `switchInputMethod`s to it, then hides.
